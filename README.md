# Product builder IA — apprendre à orchestrer l'IA

Deux ressources complémentaires pour apprendre à **décider, déléguer à des agents IA et vérifier ce qu'ils produisent**.

| Dossier | Quoi | Comment l'utiliser |
|---|---|---|
| [`cursus-orchestrateur/`](cursus-orchestrateur/index.html) | Un cursus complet en HTML : 12 modules (~24 semaines), un fil rouge (l'application fictive *Facturo*), schémas, exercices corrigés, quiz, glossaire. **Commence par la page « Démarrer » : le B.A.-BA du cursus est de chercher, vérifier et se tenir à jour.** | Ouvre `cursus-orchestrateur/index.html` dans un navigateur. |
| [`cursus-learning-app/`](cursus-learning-app/README.md) | Un cours **interactif dans ta CLI d'agent de code** (Claude Code, Codex, Mistral Vibe, Gemini CLI…). Tu joues un prestataire qui construit, pour une cliente fictive, un jeu web 2D multijoueur. Un mentor (l'agent) te fait chercher, te pose des questions et glisse parfois des erreurs à trouver. | `cd cursus-learning-app`, lance ta CLI, dis « Commençons. » |

Le cours interactif s'appuie sur le cursus : chaque phase renvoie vers les leçons utiles.

## À savoir

- Le cursus et le cours ont été rédigés avec l'aide d'un agent IA et peuvent contenir des erreurs : **vérifie** avec la
  documentation officielle, c'est justement la première compétence enseignée.
- Les outils d'agents évoluent vite : les modules 7 à 9 reposent sur des documentations consultées en novembre 2026.
- Le scénario secret de la cliente et le registre des pièges du cours interactif ne sont **pas publiés** : le mentor génère les siens
  (voir `cursus-learning-app/.agent/apprenant/README.md`).
