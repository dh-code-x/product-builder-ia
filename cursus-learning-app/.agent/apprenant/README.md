# .agent/apprenant/ — privé, ignoré par Git

Tout ce qui est **personnel à un apprenant** ou **secret** vit ici. Rien de ce dossier n'est versionné, sauf ce README.

| Fichier | Contenu | Créé par |
|---|---|---|
| `progress.md` | État : phase courante, skills installés, preuves, notes du mentor | le mentor, à la première session (copie de `../docs/modeles/progress.md`) |
| `traps-ledger.md` | Registre des pièges injectés et débriefés | le mentor (copie de `../docs/modeles/traps-ledger.md`) |
| `scenario/` | Dossier secret de la cliente (`client-bible.md`) et événements (`S0x-*.md`) | l'auteur du cours, ou **le mentor** s'ils sont absents (cf. skill `mentor-client`) |

**Honor system** : ne lis ni `scenario/` ni `traps-ledger.md` tant qu'un piège est actif ou que le scénario n'est pas joué :
les découvrir par tes propres questions est l'exercice.
