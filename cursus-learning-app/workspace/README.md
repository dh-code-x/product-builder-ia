# workspace/ — ton projet

Tout ce que tu produis vit ici : documents (`docs/`), code du jeu, `AGENT.md` du jeu (phase 4).

- **Dépôt Git indépendant** : `git init` ici en phase 0. Ce dossier est *ton* dépôt, distinct du cours.
- `docs/journal-de-bord.md` : à chaque session, 3 lignes — ce que j'ai appris / vérifié / rejeté de l'IA.
- `docs/carnet-de-veille.md` (plan + journal de veille, 30 min/semaine) et `docs/carnet-de-derives.md` : [modèles](../courses/_modeles/carnets.md).
- Nommage des livrables : `docs/NN-sujet.md` (NN = numéro de phase).
- Chaque livrable produit avec l'IA se termine par un bloc de [traçabilité](../courses/_modeles/tracabilite.md).
